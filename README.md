# Димарик Smokes — раскидки дымов CS2

Одно приложение — ПК, Android, iOS. Внутри: 7 карт активного пула CS2 (октябрь 2026),
40 проверенных русскоязычных видео, собственный плеер (A-B повтор, скорость, качество,
горячие клавиши, жесты, запоминание позиции), избранное, релакс-музыка, уникальный дизайн каждой карты.

## Запустить сразу (ПК)
Открой `index.html` в браузере — или запусти локальный сервер (нужно для офлайн-режима/PWA):
```
python -m http.server 8080      # либо: npx serve -l 8080 .
```
Открой http://localhost:8080 → в Chrome/Edge нажми «Установить приложение» в адресной строке.

## Android (3 способа)
1. **PWA:** открой сайт в Chrome → «Добавить на главный экран». Работает как приложение.
2. **APK через Capacitor:**
   ```
   npm i
   npx cap add android
   npx cap sync
   npx cap open android   # Android Studio → Build → APK
   ```
3. **APK через PWABuilder:** залей папку на любой хостинг (GitHub Pages, Netlify) и вставь ссылку на https://pwabuilder.com → скачай APK/AAB.

## iOS
1. **PWA:** Safari → «Поделиться» → «На экран Домой». Иконка и полноэкранный режим уже настроены.
2. **App Store (IPA):** `npm i && npx cap add ios && npx cap sync && npx cap open ios` → Xcode → Archive.

## Десктоп-приложение (exe/dmg)
```
npm i
npm run desktop          # запуск
npx electron-builder     # сборка установщика (опционально)
```

## YouTube и RuTube (без VPN)
В России YouTube замедлен/заблокирован, поэтому у видео есть **зеркала на RuTube**: кнопка «RuTube · без VPN» над плеером,
фильтр «Только без VPN» на странице карты, а в Настройках — источник по умолчанию (Авто / RuTube / YouTube).
В режиме «Авто» приложение само переключается на RuTube, если YouTube не отвечает 9 секунд.
Зеркала в `data.js`: поле `rt` (id RuTube); видео только с RuTube имеют `id: "rt_…"`.

## Если видео не запускается
- **Открывай приложение в отдельной вкладке браузера**, а не во встроенном превью: песочницы часто режут всплывающие окна и внешние скрипты.
- В России YouTube может быть замедлен — плеер покажет панель с вариантами: «Простой плеер» (запасной способ встраивания), «Открыть на YouTube», «Искать на RuTube», копирование ссылки. При включённом VPN всё работает штатно.
- Кнопки «Открыть на YouTube» в среде без всплывающих окон автоматически копируют ссылку в буфер.

## Структура
- `index.html` — всё приложение (разметка, стили, логика, плеер, музыка)
- `data.js` — база видео по картам (добавляй свои: id с YouTube, название, автор)
- `sw.js`, `manifest.json`, `icons/` — PWA
- `capacitor.config.json`, `electron.js` — обёртки под мобильные и ПК

## Как добавить видео
В `data.js` в массив `videos` нужной карты:
```js
{ id: "YOUTUBE_ID", title: "Название", author: "Автор", dur: "4:20", fresh: "1 мес.", views: "10 тыс.", note: "Комментарий" }
```
