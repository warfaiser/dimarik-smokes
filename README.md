## Как добавить видео

Все ролики лежат в `data.js` — одна запись = одно видео:

```js
{id:'YouTube_ID', rt:'rutube_id', title:'Название', author:'Автор', dur:'4:35', fresh:'2 мес.', note:'Заметка', hot:true}
```

`rt` — необязательное зеркало на RuTube. Если видео есть только на RuTube, укажи `id:'rt_xxxxxxxx'`.

## Технологии

Чистый HTML/CSS/JS, без фреймворков и сборки. PWA с офлайн-оболочкой (`sw.js`), музыка генерируется через Web Audio API.
